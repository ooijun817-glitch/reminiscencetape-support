# Reminisce のサポートのページ

App Store に載せる、Reminisce(iPhone のカセット・プレーヤーのアプリ)のサポート・プライバシーポリシー・利用規約・特定商取引法に基づく表示のページ。GitHub Pages で公開する。

- index.html:サポート(App Store の「サポート URL」)
- privacy.html:プライバシーポリシー(App Store の「プライバシーポリシー URL」)
- terms.html:利用規約
- tokushoho.html:特定商取引法に基づく表示
- style.css:PLANT ARCHIVE のサポートのページと同じ見た目
